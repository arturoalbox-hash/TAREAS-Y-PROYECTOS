Prácticas de la asignatura DWES — 2º DAW, MEDAC Almería.
Autor: Arturo Jimenes Navarrete.

## Tema 2 · Primeros pasos en PHP

| Actividad | Descripción | Archivo |
|---|---|---|
| [Actividad 1](Tema2/Actividad1) | Tipos de datos sencillos (entero, decimal, booleano, cadena) y sus funciones de comprobación `is_int()`, `is_float()`, `is_bool()`, `is_string()` | `tipos_datos.php` |
| [Actividad 2](Tema2/Actividad2) | Operaciones aritméticas (suma, resta, multiplicación, división) con formulario para cambiar los datos y control de división entre 0 | `operaciones.php` |

Cada carpeta incluye también el PDF de entrega con capturas del código y del resultado.

## Cómo probarlo

1. Copia el `.php` a la carpeta `htdocs` de XAMPP (`C:\xampp\htdocs\`).
2. Arranca Apache en el panel de XAMPP.
3. Abre `http://localhost/tipos_datos.php` o `http://localhost/operaciones.php`
   (añade `:8080` si Apache usa ese puerto).

También funciona con el servidor integrado de PHP: `php -S localhost:8000`.
